# M17 — Public chat integration

Validation: local verify-m17 replay and separate J8 completed.
Commit-specific CI evidence is attached to the delivery pull requests.
Project scope is resolved before vision. Only validated server conversation
history and the current upload reach vision; descriptions are stored without
image bytes. The permanent API regression covers both isolation and successful
current uploads. J5 replays an Alpha image in client history after selecting Beta
and requires an isolated final answer with exact recorded provider requests.

Requirements: MISSION M17 J1–J8, POC-F1/F3/F5, REQ-ENG-009.
The HTTP journeys cover French answers and vision, resolved corpus citations,
a generated 512×512 PNG, project memory reuse/isolation, and web synthesis after
completed search and fetch. Auxiliary generation is explicitly disabled.
Local live evidence is archived in `BRAIN/m17-live-report.json`; CI replays actual
provider exchanges through the adapter. J8 runs separately and restarts the stack.
Image generation requires the documented warm GPU; the test GPU was destroyed.
No threshold or protected assertion was relaxed. Reservation still covers both
members of every fallback pair within the unchanged 0.05 EUR request cap.
Language classification uses seeded langdetect 1.0.9 (MIT, about 2.38 MB, dependency
six); the earlier word ratio misclassified French auxiliary verbs. English/code
negative checks retain the 0.8 confidence threshold. The package is mature but
old; its use is bounded to language detection, with no network access.
See `runbooks/chat.md` for commands, explicit recording modes and prerequisites.

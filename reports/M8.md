# M8 — routage serverless

REQ-INF-004, REQ-MOD-004, REQ-ENG-004/006/009, REQ-FIN-002, POC-P6.
Contrat : `contracts/m8.md`. Modèles, capacités et prix restent dans le gateway.
Le chat sans GPU route texte/code/vision ; un fallback conserve délai et réserve
budgétaire. Les logs exposent tokens, coût mesuré et réserve d'une panne sans usage.

Source: catalogue et tarifs officiels Scaleway, consultés le 2026-09-10 :
https://www.scaleway.com/en/docs/generative-apis/reference-content/supported-models/
https://www.scaleway.com/en/pricing/model-as-a-service/

Sondes synthétiques enregistrées : 7,720 s, 0,0013905 EUR mesurés ; réservation
0,1044521 EUR, chaque requête sous 0,05 EUR. Texte/code servis par les alias prévus,
calculator appelé avec 19*23, plusieurs fragments SSE puis DONE, embeddings 1024D,
carré rouge reconnu, bascule code→texte après panne injectée exclusivement en test.
Deux sondes préalables d'images rouges uniformes (32 puis 256 pixels) ont donné une
couleur erronée. Cette limite qualitative reste ouverte ; elle n'est pas effacée
par la réussite du carré sur fond blanc. Aucune interaction réelle utilisée.

`make verify-m8` rejoue exactement les réponses ; `ATLAS_M8_MODE=record` renouvelle
les mesures via Scaleway. La CI appelle le gate sans dépense. Le support SSE concerne
le fournisseur (UI progressive : M11), l'upload : M12. Les index CPU M2 existants
restent compatibles ; l'alias embeddings serverless est configuré et sondé.
Le gate local seul ne constitue pas une validation CI du jalon.

Total mesuré de cette reprise, sondes échouées incluses : 0,0033931 EUR.
Couverture ciblée : 92 % (politique 95 %, transport 91 %) ; 165 tests locaux.

Reprise : le gate M7 révélait un contexte RAG trop coûteux à réserver pour deux
appels. Sélection de passages entiers par pertinence sous 4 KiB, retrieval@8 conservé.
Rejeu synthétique renouvelé : 0,003033 EUR fournisseur, 0,015813 EUR comptabilisés
conservativement ; citation résolue et 190 tests locaux. Plafond 0,05 EUR inchangé.

# M9 — mémoire et projets

Source: docs/15 M9 ; contracts/m9.md ; REQ-ENG-002/004/005/007/009,
REQ-FIN-002 et POC-P6.

Les projets regroupent instructions, conversations, documents et faits durables.
Le contexte documentaire et les faits sont partagés seulement entre les
conversations du même projet. Les faits sont extraits automatiquement du nouveau
message utilisateur ; ils sont inspectables, corrigeables et effaçables.
Une révision invalide les extractions en cours après correction/effacement et
retire les anciens échanges du contexte actif. Les archives restent inspectables.
La mémoire est explicitement distinguée des citations documentaires.

L'interface locale est disponible sur `/project-ui` de l'adaptateur, port 8020
avec `make serve` et un tunnel SSH. Elle propose sélection/création des projets
et conversations, instructions, notes/documents textuels, chat et édition de faits.
Les réponses sont rendues comme texte ; seules les citations locales validées
créent des liens. Les formats binaires restent extractibles avec le pipeline M2.

Le mode projet ignore l'historique transmis par le client et charge le contexte
via l'API retrieval. Il ne transmet pas la mémoire à la recherche web. Les appels
au gateway partagent le plafond existant de 0,05 EUR et 120 s par requête.
Le stockage privé reste local sous BRAIN, ignoré par Git (répertoire 0700,
fichier 0600). Aucun GPU ni nouvelle dépendance n'est nécessaire.

## Vérification

`make verify-m9` exécute le vérificateur protégé ; `make test-memory` produit
BRAIN/eval/memory.json seulement après succès des assertions synthétiques.
Le gate est raccordé à la CI existante via scripts/test.sh.

Les tests couvrent persistance, réutilisation, portée des documents/citations,
effacement/correction pendant extraction, transport invalide, budget, erreurs,
origines navigateur et proxy local. La validation réelle sur trois requêtes
synthétiques a également confirmé extraction, réutilisation et effacement,
pour 0,0022254 EUR mesurés. Aucun journal d'interaction réelle n'a été consulté.

Les résultats locaux ne constituent pas la validation du jalon : le job GitHub
`ci` doit exécuter le gate et être vert avant la fusion finale. La preuve CI
courante et l'état d'avancement sont consignés dans BRAIN/STATUS.md.

Limites PoC : mono-utilisateur local ; sélection de faits par pertinence lexicale ;
interface basique ; tests UI HTTP et syntaxe/contrôles DOM statiques, sans navigateur
graphique automatisé. La synthèse des grandes entrées relève de M10.

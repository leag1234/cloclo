# M10 — sélection dans les grandes sources

REQ-MOD-004, POC-P6, contrat `contracts/m10.md` (PR #38).
Le runtime recherche les passages pertinents dans tout le texte web extrait,
conserve leurs offsets, URL et date, puis fournit un contexte borné au modèle.
Le cache conserve la source complète et recalcule la sélection par question.
Les passages documentaires suivent la même sélection après retrieval hybride.
La question utilisateur est transmise par les deux points d'entrée HTTP/chat.

Source: tests anticipés rouges (module absent et preuve documentaire perdue),
puis sélection, cache, Unicode, offsets, continuation et résolution testés.
Le test synthétique M7 est réenregistré car le contexte et le schéma ont changé ;
le rejeu continue à exiger une égalité exacte des requêtes.
Aucune dépendance nouvelle, aucun GPU, aucune synthèse payante ajoutée.
Les enveloppes non fiables, SSRF, robots.txt et budgets existants restent actifs.

Limites : sélection lexicale, sans garantie sémantique interlangue ; limites
transport et plafond global de contexte toujours applicables. Les clients anciens
sans question conservent la continuation. M10 reste en attente de son gate CI.

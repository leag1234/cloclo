# M21 — Expert answers with bounded reasoning and complete evidence

Requirements: MISSION M21 D1–D5, REQ-ENG-004/005/009/011, REQ-FIN-002,
POC-F1/F2/F4/F5. Owner budget exception dated 2026-09-17 applies.

The public model selector offers atlas (none, 3000 output tokens, 0.05 EUR)
and atlas-deep (high, 16000 output tokens, 0.10 EUR). Model selection owns the
profile; user input cannot increase its ceilings. Internal legacy gateway clients
retain their 2048-token default. Prompts, routing and tools are shared.

Output includes reasoning tokens. Empty content with finish_reason=length permits
one retry without reasoning, within the original deadline and financial ledger.
The retry's input and output reservation is made before I/O. Unknown usage remains
reserved. Trace/answer token accounting uses provider usage when supplied and
identifies estimates otherwise; never mislabel characters as measured tokens.
The trace is separate and collapsed. Status explicitly identifies a reasoning retry.

The adapter sends an immediate activity state and elapsed seconds, continues updates
while inference is pending, and names tool operations and consulted URLs. Tool and
trace details are collapsed above the answer. User messages have a green background
in the existing Open WebUI integration.

Web extraction precedes budgeting. Complete extracted text and complete RAG chunks
are delivered when they fit a token budget. Oversized sources require bounded
hierarchical synthesis and relevant passages, with explicit coverage and provenance;
any incomplete coverage is disclosed. Existing SSRF and untrusted-source rules apply.

Validated uploads are stored once with opaque local references. Prior turns carry
references; only selected current evidence is materialized for vision. Existing
per-image/pixel ceilings apply. No arbitrary URL retrieval is introduced. Ten turns
with a distinct photo per turn must remain usable; references are returned to clients
so subsequent requests can avoid retransmitting base64.

Validation: J27–J33 through HTTP with actual recorded provider exchanges for CI;
unit tests cover profile ceilings, retry accounting, cancellation, first activity,
full source coverage, RAG tail citations, ten-turn images and reference rejection.
The protected verify-m21 script is invoked locally and by scripts/test.sh in CI.

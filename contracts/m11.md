# M11 — flux progressif et réflexion séparée

Exigences : POC-F1/F5, POC-P6, REQ-MOD-004, REQ-FIN-002,
REQ-ENG-004/005/007/009 ; docs/15 M11. Extension du contrat M7.

## Flux public

POST /v1/chat/completions conserve son contrat JSON quand stream=false.
Avec stream=true, réponse text/event-stream : événements data JSON
chat.completion.chunk, identifiant stable, delta.content progressif, événement
terminal finish_reason et usage, puis data: [DONE]. Pas de découpage artificiel
d'une réponse déjà terminée. Le premier delta doit pouvoir atteindre le client
alors que le fournisseur attend encore avant de produire la suite.

Les outils internes restent exécutés par le harness borné. Leurs arguments ne
sont jamais présentés comme texte assistant. Le texte intermédiaire éventuel
est distingué de la réponse finale. Les citations documentaires ne deviennent
des liens qu'après résolution contre les passages effectivement récupérés.

Option reasoning_effort : none par défaut, low sur demande explicite. Si le
fournisseur expose reasoning_content, transport dans delta.reasoning_content,
séparé de content (compatible affichage réflexion Open WebUI). Aucune réflexion
fabriquée quand le fournisseur n'en retourne pas. Métadonnées atlas indiquent
l'activation, le plafond partagé de sortie et le coût réservé ; les tokens de
réflexion font partie de la sortie facturée, pas d'un budget additionnel.

Après les en-têtes SSE, les erreurs sont des événements error à code typé
sans détail fournisseur, suivis de [DONE] ; jamais de finish_reason=stop réussi
sur flux incomplet. Les erreurs de validation avant ouverture restent JSON 4xx.
Annulation/déconnexion ferme le flux amont et annule la tâche de génération.
Un seul journal local est écrit, y compris annulation, sans secret.

## Frontière gateway et budgets

Extension interne /agent/stream : même entrée que /agent/complete, plus
reasoning_effort none|low ; sortie SSE de deltas et résultat terminal validé
(texte, appels assemblés, usage, observation), ou erreur typée. Les noms de
modèles et secrets restent exclusivement dans model-gateway.

Les fragments UTF-8/SSE et appels d'outils fragmentés sont assemblés avec des
limites explicites. Le flux est invalide si usage ou fin fournisseur manque.
Le timeout inclut toute la lecture, les queues sont bornées ; aucun retry après
émission de texte. L'annulation ferme la connexion HTTP fournisseur.

Chaque appel reste réservé AVANT I/O dans le ledger existant : sortie totale
au plus 2048 tokens, requête au plus 16384 tokens/10 outils/120 s/0,05 EUR.
Usage inconnu après arrêt : réservation conservée. La réflexion ne contourne
ni le plafond de sortie ni le plafond financier. Aucun GPU requis.

## Vérification

make test-streaming produit BRAIN/eval/streaming.json : nombre de deltas de
contenu, preuve de réception avant fin amont, temps et coût/réservation.
make verify-m11 appelle le vérificateur protégé inchangé ; scripts/test.sh
l'exécute dans le job ci existant. Tests réseau local à fournisseur enregistré
ou transport contrôlé exclusivement dans tests, sans appel LLM payant en CI.

Cas : progression réelle avec barrière fournisseur, Unicode fragmenté,
appels d'outils fragmentés, réflexion séparée/absente, citations résolues,
usage absent/invalide, flux tronqué, erreur fournisseur, timeout, annulation,
client lent, refus avant appel quand budget insuffisant. Une sonde synthétique
Scaleway peut fournir une cassette, bornée à 0,05 EUR/requête ; aucune lecture
ni publication des interactions réelles.

# M4 — cascade S → L
Source: docs/13 POC-F6/E8, REQ-INF-003/004, REQ-ENG-004/006, REQ-FIN-002.
Contrat et code dans la même PR autorisés par mandat M4.

POST /agent/complete conserve le contrat M3. Le gateway classe les messages
utilisateur : tâches courtes explicitement simples vers local ; besoin de
raisonnement, historique outil ou entrée inconnue vers Scaleway. Le classifieur
est pur, sans accès aux étiquettes E8 ; décision et raison journalisées sans texte.
La configuration routing.yaml fournit endpoints et modèles par environnement.
Si le local est absent, inaccessible, invalide ou expire, une seule bascule L ;
aucun retry L. Tentative locale <=2 s et <=20% du délai restant, deadline globale
inchangée. Prix L réservé par le harness existant ; local sans coût serverless.
Erreurs L explicites selon M3 ; aucune réponse factice hors tests.

AC : décision simple/complexe, Unicode, vide/géant, historique complexe,
endpoint local réellement fermé, réponse locale valide, erreur/timeout local,
échec L propagé, enveloppe inchangée et absence de secret dans les logs.
E8 : rapport accuracy, matrice, ventilation par langue, sous_routage_critique,
statuts et décisions par cas. Seuil >=0.85 et aucun critique sous-routé.
Référence E8 validée humainement dans le commit 8167ca9.
Tests CI sans LLM live ; test de transport injecté exclusivement sous tests/.
Plan : gateway, tests, Makefile, scripts/test.sh ; fichiers protégés inchangés.
Coût infra additionnel 0 EUR/h, aucun GPU créé. Pas de dépendance nouvelle.
UI bonus non bloquant selon MISSION ; pas d'UI développée dans ce jalon.

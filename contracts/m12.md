# M12 — entrée image souveraine

Exigences : docs/15 M12 ; REQ-ENG-004/005/009, REQ-FIN-002,
POC-P6. Extension additive du contrat M7, préalable à l'implémentation.

## Entrée publique et UI

POST /v1/chat/completions conserve les messages texte. Le contenu utilisateur
peut aussi être une liste de parties OpenAI-compatible :
- {type: text, text: chaîne non vide} ;
- {type: image_url, image_url: {url: data:image/png;base64,...}}
  (JPEG également accepté ; detail auto/low/high facultatif).

Une à quatre images par requête, au plus 2 Mio décodés par image et 4 Mio
au total ; dimensions positives, au plus 4096 par axe et 16 millions de pixels
cumulés. Validation réelle du format, base64 stricte, absence de fichiers
tronqués ; aucun téléchargement d'URL distante, accès disque ou SVG.
Le corps HTTP est borné avant parsing (6 Mio). Les images ne sont acceptées
que dans les messages user ; une question textuelle reste obligatoire dans
le dernier message. Les limites historiques du texte restent applicables.

L'upload natif Open WebUI transmet l'image en data URI. Vérifier cette
configuration et une requête multimodale complète ; ne pas annoncer de
validation navigateur sur la seule base d'un test HTTP.

## Gateway et traitement

Toute requête contenant une image utilise un endpoint vision interne dédié ;
le gateway seul connaît le modèle vision et son tarif, configurés dans
services/model-gateway. Fournisseur : Scaleway Generative APIs, aucun GPU
local. Images et historique sont transmis au modèle vision, sans conversion
en une simple description supposée ni fallback vers un modèle texte.
Les instructions de prompt vivent dans prompts/. Les outils à effet de bord
restent absents. Le chemin texte M7 conserve son comportement.

Réservation conservative avant inférence : texte, enveloppe maximale des tokens
image et sortie, au tarif configuré ; rejet avant transport si >0,05 EUR.
Usage réel contrôlé, coût conservateur maintenu si usage absent ou invalide ;
plafond total 120 s, sortie au plus 2048 tokens. Aucun retry caché.
Retour compatible M7 : texte, usage, observation escalade/complexe et coût.
Erreurs typées : entrée invalide/volumineuse, budget, timeout, fournisseur ;
aucune exception brute, clé, payload image ou header dans les erreurs.
Le SSE conserve le contrat atomique M7 jusqu'à intégration de M11.

## Observabilité et preuves

Journal local : question textuelle, réponse, nombre/format/dimensions des images,
route vision, tokens/coût/latence et erreurs ; jamais les octets/base64 des images.
Aucune interaction réelle ne quitte BRAIN/interactions, ignoré par Git.

make test-vision teste description et question de contenu sur une image
synthétique versionnée sans secret. En mode live : requêtes Scaleway bornées,
enregistrements synthétiques et mesures ; en CI : rejeu de ces enregistrements,
aucun appel LLM live. Rapport BRAIN/eval/vision.json : described vrai seulement
si les assertions sémantiques des deux réponses et le routage sont vérifiés.
Tests négatifs : format invalide, base64, limites, URL privée/distante refusée,
image uniquement, rôle interdit, budget avant transport, timeout, usage absent,
image jamais journalisée, non-régression texte. make verify-m12 appelle le script
protégé intact ; scripts/test.sh inclut le gate et son rejeu dans la CI existante.
